# Tuba Kavgacı — Cybersecurity Portfolio

A professional, responsive portfolio and résumé website showcasing Tuba Kavgacı's experience in cybersecurity, security operations, cyber threat intelligence, and digital forensics.

**Live website:** https://tubakvgc.github.io/tubakavgac-.github.io/

## Sections

- Introduction and professional profile
- Professional cybersecurity experience, earlier internships at GAIS Cyber Security and DSET, and education (Digital Forensics Engineering graduate; Business Management at Atatürk University, currently in progress)
- Selected public projects
- Vulnerability research and CVE proof-of-concepts
- Publications and technical writing
- Community talks and training
- Contact and social profiles

## Features

- Clean dark-navy visual identity with accessible contrast
- Responsive layout and mobile navigation
- Turkish/English language switcher (TR / EN), with automatic browser-language detection and saved preference
- Bilingual hero headline: *They search for vulnerabilities. I investigate them.*
- No JavaScript frameworks or build tools required
- SEO metadata, Open Graph tags, and Person structured data
- Reduced-motion and print styles for **Save as PDF**
- External links use `rel="noopener noreferrer"`
- Content is curated manually rather than relying on third-party RSS APIs

## Deployment

This is a static website intended for GitHub Pages. Publish the `main` branch from the repository root under **Settings → Pages → Build and deployment**.

The site URL is expected to be:

https://tubakvgc.github.io/tubakavgac-.github.io/

> Because this repository is not named `tubakvgc.github.io`, it is deployed as a **project site** under a URL path, not at the GitHub username root.

## Updating content

Edit `index.html` to change the experience, featured projects, publications, or speaking engagements. When adding new text, add its Turkish equivalent to the `translations` dictionary in `i18n.js`. The English page is the source language. Use only public and verifiable professional information. Avoid adding internal company architecture, secrets, confidential threat intelligence, or credentials.
